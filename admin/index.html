Lấy mã truy cập ở đâu?
  1. Mở trang tạo token của GitHub (đăng nhập tài khoản sở hữu repo).
  2. Đặt tên, ví dụ Quản trị web, chọn thời hạn (Expiration).
  3. Repository access → Only select repositories → chọn repo của web.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Bấm Generate token, chép mã rồi dán vào ô trên.
